# Battlefield Art Brief: Cursed Classroom (Module 1)

The combat scene is built from separate layers so most of it can move: candles flicker, the
moon glows, papers drift, lanes pulse. Some layers are drawn in code (lanes, lights, particles,
effects, HUD). The pieces below need to be **painted**: generated by AI or found online with a
licence that allows use. Until a piece exists, the game draws a placeholder in its place.

Reference: `Design/level prototype.png` (layout and mood) and the enemy cut-outs in
`Sprites/characters/` (style).

## Style rules (apply to every prompt)

- **Look:** stylized 2D cartoon, painted, thick dark outlines, soft cel shading, slightly
  grungy texture, like the existing pencil/textbook enemies. *Not* pixel art, *not* 3D, *not* photo.
- **Mood:** a school classroom at night that has been cursed. Cool purple and blue moonlight
  from the back windows, warm orange pools of candlelight, cyan magic.
- **Camera:** high three-quarter view looking down at the floor, the room receding up and to
  the right (as in the prototype). Every piece must match this angle.
- **Light direction:** moonlight from the back left (windows), candles as local warm lights.
- **Palette anchors:** wall `#1b1430` to `#3a2a58`, floor `#2e2840` to `#4a3c50`,
  moonlight `#b9a8ff`, candlelight `#ffa040`, magic `#3fe0ff`.
- **No text, no UI, no characters** in background pieces (the game adds those).

Append this to every prompt:

> stylized 2D cartoon game art, hand-painted look, thick dark outlines, soft cel shading,
> night-time cursed classroom, purple moonlight and warm candlelight, high three-quarter
> top-down view, no text, no characters, no UI

## Getting a piece into the game

1. Generate it. If your tool can't output transparency, remove the background (for example
   with remove.bg or Photoshop's Remove Background) and save as PNG.
2. Put the full-size file in `Sprites/<group>/` (outside the repo; originals don't go in git).
3. Shrink it for the game:

   ```
   python scripts/optimize-art.py ../Sprites/characters public/assets/combat/enemies --height 320
   python scripts/optimize-art.py ../Sprites/room public/assets/combat/room --height 1080 --no-trim
   ```

   This trims transparent edges, resizes and saves WebP (typically 1-2 MB → 20-80 KB).
4. Tell the combat developer, who will add it to `src/combat/view/theme.ts` and line up
   the lanes and lights with it.
